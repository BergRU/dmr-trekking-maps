# DMR Trekking: офлайн-карты OpenStreetMap

Векторные офлайн-карты для программы DMR Trekking (карта штаба поисково-спасательного отряда). Карты нарезаны по
восьми федеральным округам: ЦФО, СЗФО, ЮФО, СКФО, ПФО, УрФО, СФО, ДФО.

## Что внутри

- Формат: MBTiles с векторными тайлами (`format=pbf`, схема Protomaps Basemap), до масштаба z14.
- В каждом файле до z5 лежит вся Россия (обзор), с z6 до z14 — только свой округ. На границах округа перекрываются.
- Сборка Protomaps `20261105` (данные OpenStreetMap на 05.11.2026). Каждый файл меньше 2 ГиБ.
- Файлы лежат в выпусках (Releases) этого репозитория. Название выпуска — `osm-ГГГГ-ММ-ДД`. Подписанный список
  пакетов `dmrtrek-packs.json` и подпись `dmrtrek-packs.json.sig` — в постоянном выпуске `index`.
- Баз базовых станций в этом репозитории нет.

## Как поставить

Ноутбук:

1. В программе откройте «📦 Обновления данных». Если адрес списка пакетов задан, программа сама покажет карты,
   проверит подпись и скачает нужные округа.
2. Либо скачайте файл нужного округа из выпуска и нажмите «Добавить файл».

Телефон: карты приходят с ноутбука штаба по Wi-Fi штаба (раздел обновлений данных на ноутбуке). Файл можно также
положить на телефон вручную и добавить через «Добавить файл» в приложении.

Файл — один округ целиком, ставьте только те округа, где работает отряд.
